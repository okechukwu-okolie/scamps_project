SCAPMS - Windows portable package

To run:
1. Extract all files from the ZIP into the same folder.
2. Double-click SCAPMS.exe.

Keep the two DLL files beside SCAPMS.exe. They are required runtime libraries.
Clinic data is saved in clinic_data.txt in the folder from which the program is run.

This build is for Windows. It is not a website and does not run in a browser.
